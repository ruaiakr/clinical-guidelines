<h1 class="pccm-page-title">Fitting - convulsions, seizures – Adult/Child</h1>

<div class="pccm-guideline-panel">
<h2 class="pccm-section-heading">Recommend<sup>1,2</sup></h2>
<ul>
<li>Status epilepticus is continuous seizure activity or repeated seizures without full recovery to normal LOC between episodes - neurological emergency, aim to stop seizure urgently<sup>1,2</sup></li>
</ul>
<h2 class="pccm-section-heading">Background</h2>
<ul>
<li>Most fits are brief + end within 1–3 minutes without needing midazolam<sup>2</sup></li>
<li>Febrile convulsions occur with rapid ↑T in early acute illness in child aged 6 months–6 years<sup>1</sup></li>
</ul>
</div>

<h2 class="pccm-section-heading-blue">1. May present with</h2>
<ul class="pccm-content-list">
<li>Fitting eg:<sup>1,3</sup>
<ul>
<li>sudden body stiffening, will fall if standing</li>
<li>jerking movements, head arching back</li>
<li>shallow breathing or may stop temporarily</li>
<li>dribbling, blood stained if tongue bitten</li>
<li>± fever in child</li>
</ul>
</li>
<li>Pregnant + fitting, see Preeclampsia, for magnesium sulphate infusion + ongoing management</li>
<li>Post seizure - drowsy, confused, incontinent, agitated, noisy breathing if partial airway obstruction<sup>3</sup></li>
</ul>

<h2 class="pccm-section-heading-blue">2. Immediate management</h2>
<ul class="pccm-content-list">
<li>Fitting:<sup>2,3</sup>
<ul>
<li>protect patient’s head + avoid restraining unless essential to avoid injury</li>
<li>lay down + turn on the side when practical</li>
<li>note the time</li>
<li>maintain airway - do not force mouth open or attempt to insert object</li>
<li>insert IVC if possible</li>
<li>do BGL - if &lt; 4 adult, &lt; 3 child - treat <a href="/docs/Emergency/Hypoglycaemia">Hypoglycaemia</a>, concurrently</li>
<li>contact MO urgently</li>
</ul>
</li>
<li>Status epilepticus:<sup>1,2</sup>
<ul>
<li>if fitting &gt; 5 minutes or repeated seizures without full recovery to normal LOC</li>
<li>give Midazolam or Diazepam</li>
<li>repeat if seizure continues after 5 minutes - as per MO</li>
</ul>
</li>
<li>MO will seek urgent advice + may order 2nd line agent eg:
<ul>
<li>phenobarbitone or phenytoin<sup>1</sup></li>
</ul>
</li>
<li>Do:
<ul>
<li>GCS + vital signs. Check for ↓BP</li>
<li>check for complications eg airway, aspiration, hyperthermia, IV site for extravasation</li>
<li>monitor closely until evacuated</li>
</ul>
</li>
<li>Post seizure:
<ul>
<li>insert oropharyngeal airway if needed</li>
<li>place in recovery position<sup>3</sup></li>
<li>give O<sub>2</sub> to maintain SpO<sub>2</sub> ≥ 94%</li>
<li>reassure patient/family/carers - fitting can be extremely distressing<sup>1</sup></li>
</ul>
</li>
<li>Do vital signs + GCS</li>
</ul>

<h2 class="pccm-section-heading-blue">Look for causes + manage concurrently<sup>1,2</sup></h2>
<ul class="pccm-content-list">
<li>Suspected poisoning or drug overdose - see <a href="/docs/Emergency/Poisoning-and-overdose">Poisoning and overdose</a> (Toxicology assessment)</li>
<li>Epilepsy - adherence with therapy, recent sleep deprivation</li>
</ul>

<h2 class="pccm-section-heading-blue">3. Clinical assessment</h2>
<ul class="pccm-content-list">
<li>Ask about details leading up to fitting, including:<sup>1</sup>
<ul>
<li>prior events</li>
<li>changes in behaviour</li>
<li>signs/symptoms of illness, fever</li>
</ul>
</li>
<li>Get details of the fitting, including:<sup>1</sup>
<ul>
<li>how it started</li>
<li>any movements of eyes + limbs, symmetry of movements</li>
<li>focal movements eg rubbing of hands, lip smacking</li>
<li>estimated duration + appearance/behaviour after</li>
<li>pre-hospital treatment</li>
</ul>
</li>
<li>Get past history:<sup>1,2</sup>
<ul>
<li>previous fits or family history + previous management</li>
<li>medical/surgical eg intracranial infection, hypoglycaemia/electrolyte disturbance, neurological</li>
<li>damage/surgery eg placement of ventriculoperitoneal (VP) shunt</li>
</ul>
</li>
<li>Do physical examination, including:<sup>5</sup>
<ul>
<li>if child + fever - look for source eg URTI, pneumonia, AOM, UTI</li>
<li>assess neurological status + return to normal level of alertness + activity<sup>1</sup></li>
<li>ECG<sup>2</sup></li>
<li>check for injuries<sup>2</sup></li>
<li>pregnancy test if female of reproductive age. If +ve consider Eclampsia</li>
</ul>
</li>
</ul>

<h2 class="pccm-section-heading-blue">4. Management</h2>
<ul class="pccm-content-list">
<li>Ongoing management as per cause in collaboration with MO</li>
<li>If brief seizure &lt; 5 minutes:<sup>1,2</sup>
<ul>
<li>observe/monitor for ongoing seizures</li>
<li>further investigations as per MO</li>
<li>consider discharge if:<sup>1</sup>
<ul>
<li>cause of seizure is certain</li>
<li>no further seizures for several hours + patient is alert/responding normally</li>
<li>observations, including GCS, pupil reaction, BP, HR - within normal ranges</li>
<li>family/caregivers are able to safely manage the patient at home</li>
</ul>
</li>
</ul>
</li>
<li>If child with febrile convulsion:<sup>5</sup>
<ul>
<li>MO will advise, based on source of fever</li>
<li>give ibuprofen ± paracetamol if uncomfortable. See <a href="/docs/Pain,%20nausea%20and%20vomiting/Acute-pain">Acute pain</a></li>
<li>consider discharge if:
<ul>
<li>returned to normal age appropriate baseline neurology</li>
<li>infection source identified that can be managed in community</li>
</ul>
</li>
</ul>
</li>
<li>Advise family/carers about:<sup>1,5</sup>
<ul>
<li>first aid/how to manage subsequent seizure</li>
<li>return promptly if deterioration/another seizure</li>
</ul>
</li>
</ul>

<h2 class="pccm-section-heading-blue">5. Follow up</h2>
<ul class="pccm-content-list">
<li>If discharged, advise review the next day or sooner if concerned/recurrent seizure - contact MO urgently. Also see MO at next clinic + advise not to drive until cleared by a specialist</li>
</ul>

<h2 class="pccm-section-heading-blue">6. Referral/consultation</h2>
<ul class="pccm-content-list">
<li>MO will advise if specialist referral required</li>
</ul>
</div>
