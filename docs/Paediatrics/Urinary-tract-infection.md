<h1 class="pccm-page-title">Urinary tract infection (UTI) - Child</h1>

<div class="pccm-guideline-panel">
<h2 class="pccm-section-heading">Background</h2>
<ul class="pccm-content-list">
<li>Diagnosing a UTI in young children can be challenging as symptoms are non-specific<sup>1</sup></li>
</ul>
</div>

<h2 class="pccm-section-heading-blue" id="may-present-with">1. May present with<sup>1</sup></h2>
<ul class="pccm-content-list">
<li>Fever</li>
<li>Unwell - looks sick, irritable</li>
<li>Poor feeding, nausea, vomiting</li>
<li>Poor weight gain</li>
<li>Urinary symptoms - frequency, dysuria, haematuria, smelly urine</li>
<li>Abdominal or loin pain</li>
<li>Changes to continence in older child</li>
</ul>

<h2 class="pccm-section-heading-blue" id="immediate-management">2. Immediate management</h2>
<ul class="pccm-content-list">
<li>Do vital signs - note BP<sup>1</sup></li>
<li>Screen for <a href="/docs/Emergency/Sepsisseptic-shock">Sepsis</a></li>
</ul>

<h2 class="pccm-section-heading-blue" id="clinical-assessment">3. Clinical assessment<sup>1</sup></h2>
<ul class="pccm-content-list">
<li>Ask about:
<ul>
<li>fever</li>
<li>pain - loin, suprapubic</li>
<li>previous UTI - when, treatment</li>
<li>difficulties passing urine where age appropriate eg dribbling, straining</li>
<li>underlying conditions eg urinary tract malformations</li>
<li>consider STI history where appropriate<sup>1</sup></li>
</ul>
</li>
<li>Do:
<ul>
<li>weight - bare weight if &lt; 2 years. Assess against recent weights</li>
<li>Hydration assessment - <a href="/docs/Paediatrics/Gastroenteritisdehydration">child</a></li>
<li>palpate abdomen, check for:
<ul>
<li>palpable bladder</li>
<li>loin or suprapubic tenderness</li>
</ul>
</li>
</ul>
</li>
<li>Get clean catch urine specimen/MSU:
<ul>
<li>clean genital area with saline soaked gauze, ask child to void</li>
<li>if child/baby unable to void on request, use Quick-Wee method to encourage</li>
<li>note: bag specimens are not recommended + cannot be used for UTI diagnosis<sup>1</sup></li>
</ul>
</li>
<li>Do urinalysis. If results:
<ul>
<li>leucocytes AND nitrites - likely UTI</li>
<li>leucocytes OR nitrites - possible UTI</li>
<li>note: blood or protein is not a reliable marker of UTI<sup>1</sup> - may indicate other causes eg <a href="/docs/Paediatrics/Acute-post-streptococcal-glomerulonephritis">APSGN</a></li>
</ul>
</li>
<li>Send clean catch urine/MSU for MCS if:
<ul>
<li>leucocytes OR nitrites present</li>
<li>&lt; 3 months of age</li>
</ul>
</li>
<li>If considering gonorrhoea + chlamydia PCR urine testing in older symptomatic children:<sup>1</sup>
<ul>
<li>discuss with MO</li>
<li>see <a href="/docs/Paediatrics/Child-protection">Child protection</a></li>
</ul>
</li>
</ul>

<div class="pccm-guideline-panel">
<h2 class="pccm-section-heading">Quick-Wee<sup>1,3</sup></h2>
<ul class="pccm-content-list">
<li>Give the child/baby a breastfeed, formula, drink</li>
<li>Clean genital area with saline soaked gauze</li>
<li>Gently rub lower abdomen for a few minutes in a circular motion with a gauze soaked in cold water</li>
<li>Catch urine in sterile container</li>
</ul>

</div>

<h2 class="pccm-section-heading-blue" id="management">4. Management<sup>1</sup></h2>
<ul class="pccm-content-list">
<li>Consult MO if:
<ul>
<li>child ≤ 3 months of age</li>
<li>possible UTI from dipstick</li>
<li>unable to get urine sample</li>
</ul>
</li>
<li>Further management in collaboration with MO/MA.</li>
<li>Offer analgesia if required</li>
<li>Advise to drink plenty of water, have the child wipe from front to back after toileting, encourage the child to urinate frequently, important to give all the medicine on schedule</li>
</ul>

<h2 class="pccm-section-heading-blue" id="follow-up">5. Follow up<sup>1</sup></h2>
<ul class="pccm-content-list">
<li>Advise to be reviewed in 1–2 days</li>
<li>Check urine MCS + contact MO/MA if treatment needs modifying</li>
</ul>

<h2 class="pccm-section-heading-blue" id="referral-consultation">6. Referral/consultation</h2>
<ul class="pccm-content-list">
<li>As above</li>
</ul>
